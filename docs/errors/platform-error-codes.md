# Platform error codes

Generated from the code enums (`PlatformCode`, module `platform-errors`); do not edit by hand. Regenerate with `mvn -pl platform-error-catalogue -am verify -Dplatform.errors.write=true`. The shape and the API error format: `docs/design/error-codes.md`.

Kinds: REFUSED (the request is not allowed), FAILED (we or a dependency failed), NEEDS_PERSON (sent to a person for review), INFO (a result). 668 codes.
