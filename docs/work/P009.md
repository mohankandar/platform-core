Build module platform-licensing (package com.documentplatform.licensing, plain Java, no Spring; add to build and BOM),
per design sections 1–5:

- Licence model: customer, tenant ID, product codes, entity slots (ID + allowances), type, kind, dates, deployment,
  key ID. Allowance types: pages per month, storage, concurrent seats, named seats.
- Licence type is an issuing option: SUBSCRIPTION (default; has an expiry date, 30-day grace, then intake stops) or
  PERPETUAL (internal use; no expiry, never enters grace; has an "updates until" date). The module exposes whether a
  given product release date is covered by "updates until", so a newer app version can report "this version is not
  covered by your licence's update period" while the existing version keeps working.
- Licence kind has three values: INSTALL, PRODUCTION, NON_PRODUCTION. Install and non-production usage is recorded but
  never billable. Non-production has its own tenant/slot IDs, and the module exposes the kind so each app can show its
  "Test environment" marking (the marking itself is built later in the apps, not here).
- Ed25519 signing and verification with key IDs (JDK built-in crypto, no new dependency if possible). A canonical,
  documented file format (e.g. JSON + detached signature) so the Platform Console can produce the same later.
- Licence states: valid, expiring (60/30/7/1 days), expired in 30-day grace, expired after grace; refusal codes for
  missing, forged, tampered, wrong customer, unknown key ID. Clock-rollback detection (last time seen, small
  tolerance). A Clock is injected; tests control time.
- No hard cap on any allowance: the module only reports near (80%), at (100%) and over limit; it never blocks.
- Usage ledger interface + in-memory implementation in a testkit module: records with entity slot, period, amount,
  unit, billable flag, chained hash. Read usage per entity per month; detect a broken chain.
- Usage file export for any period: tamper-evident, no document data, no prices; each file starts from the previous
  file's final chain value so a missing period or edited record is detected; plus a verifier.
- Licence-issuing command (a small CLI main class): takes type, kind, entity slots and allowances, dates and
  deployment as options → signed licence; generates tenant and slot IDs unique against its own issued-records file;
  reads the private key via a SecretResolver-style interface (never a key in the repo; tests generate throwaway keys);
  writes an issued record without key material; logs each run.
- Specific error codes and messages for every refusal; never log key material or full signatures.
- Tests for every rule: each state boundary (exact days), grace, both types (perpetual never expires; "updates until"
  coverage), all three kinds (billable flag), refusal codes, tampering (one byte changed), key rotation (old key ID
  still verifies), clock rollback, chain break, file continuity (gap and edit detected), ID uniqueness, CLI end to end.
