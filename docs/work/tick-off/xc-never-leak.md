# Tick-off: cross-check B2.3 "never-leak" (all modules)

Counts: COVERED 66 · UNTESTED 17 · LEAKS 3   (86 places)

Scope: every place where a secret, token, key, password, client secret, raw claim, document content or (sensitive)
field value could reach a log statement, exception message, result/outcome object, `toString()`, metric tag, health
detail, diagnostic bundle, audit/history row, run log or command output. Found by: every `LOG.log(` /
`System.out|err` in `*/src/main` (testkits excluded unless noted), every `new …Exception(` that adds a variable, every
record that holds a secret, value, body or claims, every health indicator, every Micrometer meter, the diagnostic
bundle, and the four commands (setup, licence, issue-licence, crypto). Paths are short: `<module>/…/<File>.java` means
`<module>/src/main/java/com/documentplatform/…`; tests are under `src/test/java` of the module named.

COVERED = protection in code and a test that plants a secret/value and asserts it is absent (or asserts the exact
output). UNTESTED = protection in code (or nothing secret today by construction) but no test would fail if it broke.
LEAKS = the place does let one through.
