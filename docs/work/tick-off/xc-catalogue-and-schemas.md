# Tick-off: cross-checks B2.2 (error catalogue) and B2.4 (schemas)

Counts: B2.2 catalogue: DONE 4 · UNTESTED 0 · PARTLY 4 · MISSING 11 · DIFFERENT 2 · APP-SIDE 0 · DOC GAP 0
Counts: B2.4 schemas: DONE 3 · UNTESTED 1 · PARTLY 5 · MISSING 1 · DIFFERENT 0 · APP-SIDE 0 · DOC GAP 2

How this was checked (read-only, no build): the catalogue codes come from `docs/errors/platform-error-codes.json`
(648 entries, 638 distinct names, 38 families). Every `enum` under `*/src/main/java` was listed, and the ones that
implement `PlatformCode` were compared against them. Every string literal in main code that looks like a code
(`"[A-Z][A-Z0-9]*_…"`) was checked against the catalogue. 48 were not in it. Most of those are property or
environment names, config enum values or examples; the ones that are refusals or failures are listed below. Every
exception class in main code was checked for a code and for `HasPlatformCode`. For B2.4, every directory under
`*/src/main/resources/db/platform/*` was checked against its install guide, its `*Schema.verify`, the test `Pg`/`Db`
helpers (the grants each gives) and the tests.
